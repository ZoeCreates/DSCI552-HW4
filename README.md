# DSCI 552 — HW4

Open `Homework4.ipynb` in Jupyter or VS Code. Run it from this folder so that
`data/AReM` resolves correctly. The notebook includes the HW3 preprocessing
needed for HW4, all parts of Question 2, and the two ISLR solutions.

The data are included. The notebook writes feature tables, cross-validation
results, and figures into `output/`. All model settings are selected using
training data. The 19 test recordings are reserved for evaluation.

Install the Python packages in `requirements.txt` if needed. Running all cells
repeats the model searches and may take several minutes. The search grids,
random seed, and handling of the short sitting recording are stated in the
notebook. If separation prevents valid logistic Wald p-values, the notebook
reports that limitation rather than reporting misleading significance tests.
